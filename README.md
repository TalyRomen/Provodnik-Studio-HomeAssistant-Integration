# Provodnik для Home Assistant

Интеграция Home Assistant для проекта Provodnik.

## Текущее состояние

Начальная версия содержит общую память существующего веб-конструктора:
настройки сохраняются в `.storage/provodnik.memory` и доступны через
авторизованный WebSocket API Home Assistant. Читать могут авторизованные
пользователи, изменять — только администраторы.

**Приём HTML-публикаций из нативной Provodnik Studio для macOS, управление
версиями и откат ещё не реализованы.** Установка этой интеграции сама по себе
не создаёт дашборд и не устанавливает Studio.

## Установка через HACS

1. Откройте HACS → меню → «Пользовательские репозитории».
2. Добавьте `https://github.com/TalyRomen/Provodnik-Studio-HomeAssistant-Integration`, тип — «Интеграция».
3. Найдите Provodnik и скачайте интеграцию.
4. Добавьте в `configuration.yaml` одну запись, если её ещё нет:

   ```yaml
   provodnik:
   ```

5. Проверьте конфигурацию Home Assistant и перезапустите его.

В этой версии нет настройки через «Добавить интеграцию»: используется YAML.
Репозиторий предназначен для ручного добавления в HACS, в общий каталог
HACS пока не включён. Установка в живом HA через HACS ещё не проверена.

## Ручная установка

Скопируйте папку `custom_components/provodnik` в
`/config/custom_components/provodnik` вашего Home Assistant, затем выполните
шаги 4–5 выше.

Если интеграция уже установлена вручную, сначала сделайте резервную копию HA.
Домен и формат памяти сохранены; удалять `.storage/provodnik.memory` не нужно.

## API текущей версии

Все команды идут через `/api/websocket` после авторизации в HA.

| Команда | Назначение | Доступ |
| --- | --- | --- |
| `provodnik/get_core` | Прочитать ядро памяти | Авторизованный пользователь |
| `provodnik/get_part` | Прочитать часть по `name` | Авторизованный пользователь |
| `provodnik/list_parts` | Список частей | Авторизованный пользователь |
| `provodnik/save_core` | Сохранить `core` | Администратор |
| `provodnik/save_part` | Сохранить `name`, `value` | Администратор |
| `provodnik/delete_part` | Удалить часть по `name` | Администратор |
