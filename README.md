# Provodnik для Home Assistant

Интеграция принимает дашборды, опубликованные из Provodnik Studio (macOS),
хранит их версии и открывает активную версию по адресу
`http://<адрес HA>:8123/provodnik/<имя>/`.

## Установка через HACS

1. HACS → меню ⋮ → «Пользовательские репозитории».
2. Добавьте `https://github.com/TalyRomen/Provodnik-Studio-HomeAssistant-Integration`, тип — «Интеграция».
3. Найдите Provodnik, нажмите «Скачать».
4. Перезапустите Home Assistant.
5. Настройки → Устройства и службы → «Добавить интеграцию» → Provodnik.

Вместо шага 5 можно добавить в `configuration.yaml` строку `provodnik:` — так
работала версия 1.0, эта запись по-прежнему поддерживается.

## Как это работает

- Studio отправляет сборку на `POST /api/provodnik/publish/<имя>`. Публиковать
  может только **администратор** HA (токен из Studio).
- Каждая публикация — отдельная версия в `/config/provodnik/<имя>/<версия>/`.
  Версия пишется во временную папку и становится видимой целиком, так что
  оборванная загрузка не ломает работающий дашборд.
- Новая версия сразу становится активной. Хранятся последние 10; активную можно
  вернуть на любую из них из Studio.
- Открытые дашборды подписаны на смену версии и перезагружаются сами.
- `/provodnik/<имя>/` отдаётся **без авторизации**, как `/local/`. Управлять
  устройствами без входа нельзя: дашборд отправляет на страницу входа HA. Не
  кладите в сборку секреты.
- Папка `/config/provodnik` попадает в резервные копии HA.

## API

HTTP:

| Запрос | Назначение | Доступ |
| --- | --- | --- |
| `POST /api/provodnik/publish/<имя>` | Загрузить сборку `{"files": {путь: base64}, "note": "…"}` | Администратор |
| `GET /provodnik/<имя>/…` | Файлы активной версии | Без авторизации |

WebSocket (`/api/websocket`):

| Команда | Назначение | Доступ |
| --- | --- | --- |
| `provodnik/publications/list` | Публикации и их версии | Администратор |
| `provodnik/publications/activate` | Сделать активной версию `version` публикации `slug` | Администратор |
| `provodnik/publications/delete` | Удалить публикацию `slug` со всеми версиями | Администратор |
| `provodnik/publications/subscribe` | Активная версия `slug` и её смена | Любой пользователь |
| `provodnik/get_core`, `get_part`, `list_parts` | Общая память прежнего веб-конструктора | Любой пользователь |
| `provodnik/save_core`, `save_part`, `delete_part` | Запись общей памяти | Администратор |

Ограничения сборки: имя — латиница в нижнем регистре, цифры и дефис (до 40
символов); обязателен `index.html`; до 500 файлов и 12 МБ; только веб-типы
файлов (html, css, js, json, изображения, шрифты, видео).
